# Los Tribilines
Nuestro proyecto será para la perspectiva del coach y seguirá un enfoque bayesiano. La pregunta principal parte de un contexto de exclusivamente de jugadas de pase, siendo: ¿Cómo suele atacar un equipo, cómo suele defender el rival y qué señales de incertidumbre y tendencia muestra el matchup?
Para ello el coach tendrá la posibilidad de seleccionar a los oponentes y comparar el down, la distancia, la zona del campo y el estado del marcador para analizar escenarios específicos.
